# CREDITS

## Core Technologies

- **FastAPI** — Python web framework for the backend API and WebSocket server
- **WebSockets** — Real-time bidirectional communication between Maestro (teacher) and Apprentices (students)
- **Web Speech API** (`webkitSpeechRecognition`) — Browser-based voice dictation for Divine Dictation
- **Mermaid.js** — Runtime diagram/flowchart rendering from LLM-generated Mermaid code
- **deep-translator** — Translation via GoogleTranslator and MyMemoryTranslator fallback chain
- **NVIDIA NIM** — `nvidia/nemotron-3.5-super-vl-120b-a12b` LLM for translation, diagram generation, and revision summaries
- **Hermes Agent** — Agentic AI assistant used to build, scaffold, and iterate this project
- **Google Fonts** — Cinzel, IM Fell English, Caveat (typography for presentation materials)
